# AGENTS.md

DoTs (`@digitalocean/dots`) is the TypeScript client for the DigitalOcean API.
Most of the code is generated by [Kiota](https://github.com/microsoft/kiota)
from the OpenAPI spec in [digitalocean/openapi](https://github.com/digitalocean/openapi).
User docs: https://docs.digitalocean.com/reference/libraries/

## Generated code: do not hand-edit

- Files starting with `// Generated by Microsoft Kiota` (`src/dots/digitalOceanClient.ts`,
  `src/dots/models/`, `src/dots/v1/`, `src/dots/v2/` and the other request-builder
  directories under `src/dots/`) are overwritten on every `make generate`.
- `src/inference-gen/index.ts` and `src/inference-gen/InferenceClient.ts` are
  written by `scripts/postgen-inference.mjs`.
- `docs/` is TypeDoc output from `make generate-docs`.
- `DO_OPENAPI_COMMIT_SHA.txt` records the spec commit the client was built from.

Where changes go instead:

- Endpoints, parameters, schemas, descriptions: change the spec in
  `digitalocean/openapi`. The `TypeScript client generation` workflow then opens
  a `[bot]` PR here.
- Fixes to generated output that Kiota gets wrong: add a post-generation patch
  in `scripts/postgen-inference.mjs`.

Hand-written code:

- `index.ts` (package entry point)
- `src/dots/DigitalOceanApiKeyAuthenticationProvider.ts`
- `src/dots/services/`, `src/dots/streaming/`
- `src/inference-gen/inference.ts` (barrel for the `@digitalocean/dots/inference` export)
- `scripts/`, `tests/`, `examples/`

## Commands

Requires Node.js >= 20.10. Run `make help` for the full list.

- `make dev-dependencies`: install dependencies (`npm install`)
- `make lint`: ESLint
- `npm run build`: compile with `tsc`
- `make test-mocked`: mocked tests (what CI runs, with `make lint` and `npm run build`)
- `make test-integration file=droplet.test.ts`: one integration test. These need
  a real API token and create real, billable resources. Do not run them unless asked.
- `make generate`: download the published spec and regenerate (needs `kiota`).
  `SPEC_FILE=path/to/spec.yaml make generate` uses a local spec.

`npm run build` writes `.js` files next to the `.ts` sources. Only some are
tracked, so check `git status` and leave untracked build output out of commits.

## Tests

- `tests/mocked/`: Jest tests using `nock` to stub `https://api.digitalocean.com`.
  Add or update one when changing hand-written code or a postgen patch.
- `tests/integration/`: scenario tests against the live API.

## Kiota behaviors to expect

- snake_case API fields become camelCase in requests and models.
- Reserved words are renamed with an `Escaped` suffix.
