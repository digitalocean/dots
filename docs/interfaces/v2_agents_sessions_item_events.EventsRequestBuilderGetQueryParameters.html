    Interface EventsRequestBuilderGetQueryParameters

    Opens a text/event-stream of the session's canonical events, served by the MARS data plane (OHP).Each frame is event: <type> plus a data: line holding a JSON event envelope; comment lines(: keepalive) arrive about every 15s and must be ignored. Decode every data: with one envelopeparser and dispatch on the envelope's type. Every stream opens with a stream.state control frame(its data is a stream_state).Delivery is at-least-once: clients MUST de-duplicate and order by event_id (a ULID), never byseq. The same path serves two modes: - live attach (default): recent context, then an open stream that stays live until the client disconnects. Pass Last-Event-ID (or cursor) to resume strictly after the last event the client already rendered, suppressing the last-N context floor. - finite replay (replay_only=true): writes a bounded slice of the stored transcript and closes. This is what doctl agents logs uses; paginate it with replay_from.OHP serves recent history only (bounded by Kafka retention and an event window); it is not anarchive. OHP's own errors (404/429/500/503) use the DO-standard JSON {id, message, request_id}envelope (cthulhu#179797 / MARSOHS-2065); the 401 comes from the edge.
